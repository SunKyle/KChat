## 任务详细说明

### Phase 1 详细说明

#### T001: 创建 Header 组件
**功能要求**：
- 显示应用 Logo 或名称
- 显示当前使用的 AI 模型名称
- 显示连接状态指示器（在线/离线）
- 右侧添加设置按钮（预留）

**技术实现**：
- 创建 `components/Header/index.tsx`
- 使用 Tailwind CSS 进行样式设计
- 添加状态指示器的动画效果

#### T002: 增强 MessageBubble 样式
**功能要求**：
- 用户消息右对齐，AI 消息左对齐
- 添加气泡阴影和圆角优化
- 显示时间戳（相对时间格式）
- 优化头像样式

**技术实现**：
- 修改现有 `MessageBubble` 组件
- 添加时间格式化工具函数
- 优化 Tailwind 样式类

#### T003: 添加消息复制功能
**功能要求**：
- AI 消息添加复制图标按钮
- 点击后复制内容到剪贴板
- 显示"已复制"提示（2秒后消失）

**技术实现**：
- 使用 `navigator.clipboard.writeText()`
- 添加 Toast 提示组件或临时状态显示

#### T004: 添加重新生成按钮
**功能要求**：
- AI 消息添加重新生成图标按钮
- 点击后重新调用 API 生成回复
- 生成过程中显示加载状态

**技术实现**：
- 在 ChatContext 中添加 regenerateMessage 方法
- 更新 MessageBubble 组件添加按钮

#### T005: 优化打字指示器
**功能要求**：
- 替换简单的加载动画为更丰富的指示器
- 添加"AI 正在思考..."或"正在输入..."文案
- 显示已接收字符数（可选）

**技术实现**：
- 修改 `TypingIndicator` 组件
- 添加脉冲动画或打字机效果

#### T006: 优化空状态展示
**功能要求**：
- 替换简单的文字提示为更友好的欢迎页面
- 添加欢迎插图或图标
- 显示使用提示和示例问题按钮
- 快速开始按钮

**技术实现**：
- 修改 ChatArea 空状态部分
- 添加示例问题快捷按钮

### Phase 2 详细说明
